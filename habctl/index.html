FeaturesFunktionen

Daily Check-ins with StreaksTägliche Check-ins mit Streaks

Mark habits done each day. habctl tracks your current streak and longest streak automatically. Miss a day and the streak resets — simple accountability.Markiere Gewohnheiten täglich als erledigt. habctl verfolgt automatisch deinen aktuellen und deinen längsten Streak. Verpasst du einen Tag, setzt sich der Streak zurück — einfache Selbstverantwortung.

AI Weekly Coaching ReviewKI-Wochen-Coaching-Review

habctl review pulls 7 and 30-day completion data and has Claude (or GPT, Gemini, Ollama) write a coaching briefing — what's sticking, what's slipping, what to focus on next.habctl review zieht 7- und 30-Tage-Daten und lässt Claude (oder GPT, Gemini, Ollama) ein Coaching-Briefing schreiben — was funktioniert, was nachlässt, worauf als Nächstes zu achten ist.

Habit Chains & Streak AlertsHabit-Chains & Streak-Warnungen

Link habits into chains so finishing one nudges the next. streak_at_risk flags active streaks you haven't checked in today, before you lose them.Verknüpfe Gewohnheiten zu Chains, sodass das Abschließen einer die nächste anstößt. streak_at_risk markiert aktive Streaks, die du heute noch nicht bestätigt hast, bevor du sie verlierst.

MCP Server for AI AccessMCP-Server für KI-Zugriff

12 MCP tools let Claude check streaks, log or undo check-ins, run weekly reviews, and suggest new habits — enabling fully automated coaching and digests.12 MCP-Tools lassen Claude Streaks prüfen, Check-ins loggen oder rückgängig machen, Wochen-Reviews ausführen und neue Gewohnheiten vorschlagen — für vollautomatisiertes Coaching und Digests.

Command ReferenceBefehlsreferenz

habctl — cheatsheet
# Add a new habit
$ habctl add "Sport"
$ habctl add "Read 30 min"

# Check in for today
$ habctl check "Sport"
$ habctl check "Sport" --date 2026-07-10   # backfill a date

# List all habits with streaks and 30-day bars
$ habctl list
$ habctl list --format diary                # diaryctl integration

# Detailed stats for a habit
$ habctl stats "Sport"

# AI weekly coaching review
$ habctl review

# AI habit suggestions
$ habctl suggest --goal "more focus, less screen time"

# Start MCP server
$ habctl mcp

Getting Started

Installation

Clone and build each tool. Every repo has a setup.sh that compiles the binary and installs it to ~/.local/bin/.

for repo in mailctl calctl taskctl notectl budgetctl diaryctl timectl habctl; do
  git clone https://github.com/aeon022/$repo
  cd $repo && ./setup.sh && cd ..
done

Make sure ~/.local/bin is on your $PATH:

export PATH="$HOME/.local/bin:$PATH"
# add to ~/.zshrc or ~/.bashrc

Initial Sync

After installing, run the initial sync for each tool to populate the local SQLite cache:

mailctl sync      # Apple Mail → local cache
calctl sync       # Apple Calendar → local cache
taskctl sync      # Apple Reminders → local cache
notectl sync      # Obsidian vault → local index

budgetctl is import-driven — there's no background sync:

budgetctl import bank.csv --account checking

Claude Desktop Config

Add all 9 tools to Claude Desktop in one config block. Edit~/Library/Application Support/Claude/claude_desktop_config.json:

{
  "mcpServers": {
    "mailctl":   { "command": "mailctl",   "args": ["mcp"] },
    "calctl":    { "command": "calctl",    "args": ["mcp"] },
    "taskctl":   { "command": "taskctl",   "args": ["mcp"] },
    "notectl":   { "command": "notectl",   "args": ["mcp"] },
    "budgetctl": { "command": "budgetctl", "args": ["mcp"] },
    "diaryctl":  { "command": "diaryctl",  "args": ["mcp"] },
    "timectl":   { "command": "timectl",   "args": ["mcp"] },
    "habctl":    { "command": "habctl",    "args": ["mcp"] },
    "postctl":   { "command": "postctl",   "args": ["mcp"] }
  }
}

Restart Claude Desktop. All 66 MCP tools appear automatically in every conversation.

mailctl

Apple Mail bridge with TUI inbox, full-text search, compose, and 6 MCP tools. Syncs Apple Mail into a local SQLite database — all reads happen locally.

Install

git clone https://github.com/aeon022/mailctl
cd mailctl && ./setup.sh

Sync

mailctl sync          # sync inbox
mailctl sync --all    # sync all folders

CLI commands

mailctl inbox                    # open TUI inbox
mailctl inbox --json             # JSON output
mailctl search "from:alice"      # search emails
mailctl send --to bob@x.com      # compose & send
mailctl draft --subject "Hello"  # save to Drafts
mailctl thread --subject "Re:"   # view thread
mailctl accounts                 # list accounts
mailctl mcp                      # start MCP server

TUI keybindings

Safety & Spam Protection

To avoid rate limits and account bans, postctl includes built-in safeguards:

  • Queue spacing: Scheduled queue slots are spaced out automatically.
  • Overdue protection: If multiple scheduled posts become overdue (e.g., system was offline), only the oldest is posted immediately. The subsequent posts are automatically rescheduled in 20-minute intervals.
  • Safe remote deletion: Deleting a post locally automatically issues API delete calls to the remote platforms to keep feeds in sync.

AI Workflows

Once all tools are connected, Claude can orchestrate them together. A single prompt can span multiple apps and execute a dozen tool calls automatically.

Morning briefing

Ask Claude: "Give me my morning briefing". Claude callsinbox, today_tasks, and todayto pull email summaries, overdue tasks, and today's events — then synthesizes them into a prioritized briefing.

Weekly planning

Ask Claude: "Help me plan my week". Claude usesthis_week, week_tasks, find_free_slots, and get_daily_note to review your schedule and draft a plan in your Obsidian daily note.

Monthly finance review

Ask Claude: "Review my finances for June". Claude callsbudget_summary, list_transactions, anddetect_recurring_payments, then useswrite_note to save the analysis to your vault.

Email to task

Ask Claude: "Turn important emails from this week into tasks". Claude searches your inbox (search_email), identifies action items, and creates tasks in Apple Reminders (create_task).

Features

Apple Reminders Sync

Two-way sync with Apple Reminders. Your tasks stay in the Apple ecosystem, accessible from iPhone, iPad, and Mac.

Pomodoro Timer

Built-in Pomodoro timer with configurable work/break intervals. Track focus sessions per task.

Batch Operations

Complete, delete, or reschedule multiple tasks at once. Keyboard-driven TUI makes bulk edits fast.

Background Daemon

Runs as a daemon to keep tasks synced and trigger Pomodoro notifications — no terminal window required.

Command Palette

Press ":" and type an action by name — new task, sync, pomodoro — instead of memorizing shortcuts. Live-filtered as you type.

Command Reference

taskctl — cheatsheet
# Show today's tasks
$ taskctl today

# TUI task manager
$ taskctl tui

# Add a task
$ taskctl add "Review PR #42" --due today
$ taskctl add "Write docs" --due 2026-07-10 --priority high

# Complete tasks
$ taskctl done --id 1
$ taskctl done --all-today

# Pomodoro timer
$ taskctl pomodoro
$ taskctl pomodoro --task 1

# Sync with Apple Reminders
$ taskctl sync

# Start daemon
$ taskctl daemon start

# Start MCP server
$ taskctl mcp

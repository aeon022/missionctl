Funktionen

Git-Historie-Reader

Wertet Commits, Diffs und Shortstat über mehrere Repos hinweg aus. Weiß, was du gebaut hast, wie lange es gedauert hat und wann du im Flow warst.

KI-generierte Einträge

Dein konfigurierter KI-Anbieter (Anthropic, OpenAI, Gemini oder lokales Ollama — kostenlos) liest deine Commits und schreibt einen persönlichen Tagebucheintrag. Kein Report — eine Geschichte. Was schwer war, was sich gut angefühlt hat, was du gelernt hast.

Streak & Heatmap

30-Tage-Commit-Heatmap in der TUI. Verfolge Coding-Streaks und sieh deine Produktivitätsmuster auf einen Blick.

Suite-Integration

Zieht erledigte Aufgaben aus taskctl, Termine aus calctl und Zeitprotokolle aus timectl für ein vollständiges Bild deines Tages.

Befehlspalette

Drücke ":" und tippe eine Aktion nach Namen — heutigen Eintrag generieren, bearbeiten, Repos durchsuchen — statt Shortcuts auswendig zu lernen. Filtert live beim Tippen.

Befehlsreferenz

diaryctl — cheatsheet
# Register a git repo
$ diaryctl init ~/code/project --name "My Project"

# Generate today's diary entry
$ diaryctl today
$ diaryctl today --open      # open in $EDITOR

# Browse entries
$ diaryctl list
$ diaryctl show 2026-07-04

# Coding stats
$ diaryctl stats --days 30

# Registered repos
$ diaryctl repos

# TUI (heatmap + entry list)
$ diaryctl tui

# Start MCP server
$ diaryctl mcp
